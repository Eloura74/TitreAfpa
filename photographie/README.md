# Création du projet

## Installation de react

```bash
npx create-vite@latest photographie --template react
```

```bash
cd photographie
```

```bash
npm install
```

## Installation de tailwindcss

```bash
npm install -D @tailwindcss/vite
```

```bash
npm run dev
```

## Installation de docker

```bash
docker-compose up -d
```

## Creation du backend

```bash
mkdir backend
cd backend
npm init -y
npm install express mongoose dotenv
```
